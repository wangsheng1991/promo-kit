# 返工流程与审核原则

## 返工流程

当审核结论为 ❌ 时，OpenClaw 自动执行返工：

1. 读取产物原文。
2. 组合「原始任务 + 当前产物 + 修改意见」，带上同一份凝练 Profile。
3. 按对应制作层 SKILL 的流程**重新产出一版**到 `outputs/<文件名>`（修掉问题列表里的每一条）。
4. 对修改后的产物再次审核。
5. **最多返工 1 次** — 如果第二次仍不达标，直接交付当前版本并告知用户问题所在。

## 审核原则

- **宽进严出** — 大多数产物应该是 ✅ 或 ⚠️，❌ 是少数情况。
- **不追求完美** — 有小问题但整体可用就通过，不要反复返工。
- **尊重创意** — 不因为风格偏好判定不达标，只管「任务是否完成、质量是否达标」。
- **透明告知** — 无论通过还是返工，都把审核结论告诉用户。
