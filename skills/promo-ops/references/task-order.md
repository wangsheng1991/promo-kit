# 推广素材任务单 · 模板

> 用途：把「我要推广什么」写成一单，交给智能体产出**图文 + 动图 + 视频**。
> 规则：**一单一主题**（一个 slug = 一个素材包）。想推三个主题就写三张单。
> 配套：`promo-playbook.md`（怎么做的，§9 工具包 / §10 分工与门禁）、`promo-integration-plan.md`（引擎与目录设计）。

---

## 最小可用版（只填这三块就能开工）

```text
主题：<一句话说清推什么>
物料：<勾选下面第 3 节里的项，给数量>
平台：<发到哪，见第 4 节>
```

其余七块你不填，我会**先问一轮**再动手，不会自己替你编事实。

## 1. 主题与目标

| 字段 | 填什么 | 例 |
|---|---|---|
| slug | 英文小写连字符，和 content-engine 的主题目录一致 | `dlss5-framegen` |
| 推什么 | 产品 / 页面 / 仓库 / 功能，给链接 | `https://dlss5nvidia.com` 的帧生成演示 |
| 一句话卖点 | 一句人话，不用形容词堆 | 「不用装驱动，浏览器里就能改证件照规格」 |
| 目标受众 | 谁会看、他在什么处境 | 出国办签证、被照相馆退照的人 |
| 要他做什么 | 唯一一个 CTA | 进页面试一次 |
| 不做什么 | 明确排除的诉求 | 不碰「提高分数」「包过」 |

## 2. 证据（事实来源）

**这一栏是硬要求**：所有数字、效果、对比都必须能追到来源，否则合规门会直接拦。

```text
- 事实/数字 1 —— 来源链接或文件
- 事实/数字 2 —— 来源
- 我们自己的实测 —— 什么人、什么时候、怎么测的、原始数据在哪
- 竞品或行业说法 —— 谁说的、原文、日期
```

没有来源的效果声明，我会删掉或者改成有出处的话，不会替你「润色成能发的」。

## 3. 交付清单（勾选，并给数量）

| 物料 | 说明 | 数量/时长 | 归谁做 |
|---|---|---|---|
| ☐ 竖版卡组 | 1080×1440，六种骨架，逐张量化自检 | 例：5 张 | `promo-kit` |
| ☐ 长图文 / 笔记草稿 | 小红书笔记、公众号导语、知乎回答 | 例：1 篇 | 技能 + 人 |
| ☐ **动图 GIF** | 卡片动效或界面录屏 | 例：1 段，≤6 秒 | HyperFrames |
| ☐ 竖版短视频 | 9:16，带字幕 | 例：1 支 15–30 秒 | HyperFrames |
| ☐ 产品演示片 | 真实录屏 + 标注 | 例：1 支 | HyperFrames |
| ☐ 前后对比动画 | 可控擦除/对齐/标注 | 例：2 张或 1 段 G→A | HyperFrames |
| ☐ 15 秒片头 | 纯代码动效，适合开场 | 例：1 支 | `ruic-motion-reel` |
| ☐ 短帖文案 | Dev.to / Bluesky 等 | 例：各 1 条 | content-engine |

默认组合（不勾就按这个走）：**5 张竖版卡 + 1 篇笔记草稿 + 1 段 GIF + 1 支 15 秒竖版视频**。

## 4. 平台

| 平台 | 现在能做 | 发布 |
|---|---|---|
| 站点 / GitHub / Hugging Face / RSS | content-engine 直接编译 | **可自动**（Tier A） |
| Dev.to / Bluesky | 草稿 + 图片/视频上传 | 半自动，需你确认 |
| 小红书 / 知乎 / 公众号 / B站 | 只出物料与草稿 | **一律人工**，我不碰登录态 |

写清楚「每个平台各出一条」还是「一条内容改写成多平台版本」。

## 5. 品牌与口气

- 人设/账号画像：有没有现成 profile？没有的话我会先做一次，之后复用。
- 说话的底线：哪些词不用、哪些玩笑不开、有没有已经说过「不做」的诉求。
- 署名与来源：卡上要不要印出处行、印哪个（`promo-kit` 的金句卡强制要出处行）。

## 6. 素材

- 已有素材：截图、录屏、logo、字体、配色（给路径或链接）。
- 配乐音效：**默认不用外部曲库**（HeyGen 目录不等于可商用）。要用就说明授权来自哪；否则走「平台官方商业音乐库 / 自购留凭证 / 自制 / 无音乐」这条链。
- 别人的东西：图、视频、商标、案例 —— 有授权再说，没有就不进包。

## 7. 时间与优先级

```text
期望什么时候看到第一批：<日期>
先做哪一个（如果是多单）：<slug>
能不能分批交付：能 / 不能
```

## 8. 验收（我按这个自查，也请你按这个验）

- [ ] 事实、数字、对比 100% 有来源；一处无依据的绝对承诺即算失败
- [ ] 卡片逐张通过：跨度 ≥75% 画高、无理由空白带 ≤216px、四带自检、溢出 ≤4px
- [ ] 两道分数门都过：AI 味专项 ≥45/50，综合质量 ≥35/50
- [ ] 合规关 + 质量关按固定矩阵给结论（✅ / ⚠️ / ❌）
- [ ] 视频/动图过 `hyperframes lint / check / validate`
- [ ] 产物有 `manifest.json`，能从路径和 hash 追回输入
- [ ] 报出**合格物料数 / 人工审阅分钟数 / 渲染耗时**（用来取基线，第一周不看曝光量）

## 怎么把任务交给我

1. **最短**：把「最小可用版」三行贴在对话里，我一轮问齐缺的（证据、受众、CTA、不做什么），然后开工。
2. **标准**：把这张单填好，存成 `promo-orders/<slug>.md`，告诉我「按 promo-orders 里的单子做」。
3. **批量**：一个目录放多张单，说「先做 `<slug>`」，我一单一单来 —— 不要一次塞十单，事实核查和人工审稿是瓶颈。

**一单跑起来的样子**：选题评分 → 取证 → 文案与分镜 → 你签一次字（`creative.json`）→ 静态卡 → 动图/视频 → 四道门禁 → 打包成可人工发布的目录。中间只有一次必签：**规格签字**；其余是你在成品上点头。
